# AGENTS.md — правила работы в репозитории DEEPoS

Этот файл читают агенты-разработчики **до** любых изменений. Он короткий; всё остальное — в
[`docs/FIRMWARE-SPEC.md`](docs/FIRMWARE-SPEC.md).

## 1. Порядок работы

1. Читаем `docs/FIRMWARE-SPEC.md`: §1 (инварианты), §13 (этапы), §17 (правила).
2. Одна задача = одна ветка: `feat/p0-boot`, `feat/p4-launcher`, `fix/panel-init`…
3. Коммит должен быть самодостаточным: код + тест этапа + запись в `docs/journal.md`.
4. Спека меняется **отдельным** коммитом `docs: …` и только если это осознанное решение.
5. После сдачи этапа — метрики в `docs/metrics.md` (память, время загрузки, температуры, FPS).

## 2. Инварианты, которые нельзя нарушать

| # | Требование |
|---|---|
| K1 | idle ≤ 150 МБ ОЗУ, загрузка ≤ 12 с, ≤ 6 демонов, 0 кадров в покое |
| K2 | нет `oom-kill`; PSI `full avg10` < 5 %; фризов > 250 мс ≤ 1 на 10 минут |
| K3 | все 175 систем из реестра присутствуют и запускаются |
| K4 | ROM, `gamelist.xml`, сейвы, конфиги RetroArch и порты PortMaster читаются без конвертации |

Любой PR, который ломает K1–K4, отклоняется без обсуждения.

## 3. Запреты

1. Не писать в BootROM/DDR-init, не менять `idbloader` без согласования.
2. Не трогать пользовательские разделы (`DATA`, `ROMS`) без бэкапа и подтверждения.
3. Не добавлять пакеты «на всякий случай»: каждый МБ ОЗУ и секунда загрузки — под отчёт.
4. Не блокировать старт игры сетью, сканированием или обновлениями.
5. Не обещать FPS и «оптимизации», которых нет в замерах.

## 4. Секреты и локальные данные

В репозиторий **не попадают**: IP-адреса конкретных устройств, токены панели, SSH host-key,
серийники USB, ники аккаунтов, пути вида `C:\Users\<имя>`, личные почты, MAC-адреса,
приватные ключи. В документации используются плейсхолдеры `<console-ip>`, `<panel-token>`,
`<host-key>`, `<repo>`, `<mac>`.

Это проверяется автоматически:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\check-secrets.ps1   # всё дерево
powershell -NoProfile -ExecutionPolicy Bypass -File tools\setup-dev.ps1       # включить хук
```

`tools\check-secrets.ps1` возвращает exit 1 при найденной проблеме, `.githooks/pre-commit`
запускает его в режиме `-Staged`, поэтому коммит с секретом **не создаётся**. Хук включается
один раз на клон командой `tools\setup-dev.ps1` (ставит `core.hooksPath=.githooks`).

Правило «сразу»: если в тексте появился реальный адрес/токен/серийник — он заменяется
плейсхолдером **до** первого коммита, а не «потом почистим историю».

## 5. Стиль

- Документы — по-русски, код и комментарии в коде — по-английски.
- Имена этапов, тестов и файлов — как в спеке (`T1`…`T12`, `P0`…`P7`).
- Скрипты для Windows — PowerShell 5.1-совместимые, файлы `.ps1` пишутся в UTF-8 **с BOM**.
- Бинарные артефакты (BMP/PNG) генерируются скриптами (`branding/make-logo.py`), а не руками.
