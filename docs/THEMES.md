# Темы DEEPoS

Откройте **Настройки → Оформление**. Выберите тему, нажмите кнопку подтверждения для предпросмотра и ещё раз для сохранения. Предпросмотр отменяется кнопкой возврата или через 10 секунд.

## Своя тема

Создайте в корне карты ROMS папку `themes` и сохраните в неё файл `my-theme.theme`. Для имени подходят строчные латинские буквы, цифры, дефис и подчёркивание. Длина имени без расширения — до 26 символов. Скопируйте пример и измените цвета.

```ini
format = 1
layout = split
background = 0c0e11
panel = 18202c
text = f8fafc
accent = 90d3ff
```

Цвета записываются шестью цифрами RGB без `#`. Компоновки библиотеки — `grid` (сетка), `split` (список с карточкой системы), `shelf` (горизонтальный ряд), `list` (полноширинный список). Шрифт и контуры рисует сам лаунчер. Формат версии 1 поддерживает палитру и компоновку. Лаунчер проверяет размер файла, поля и контраст перед предпросмотром. После копирования заново откройте «Оформление», чтобы обновить список.

## Возврат к штатной теме

- Нажмите физические `Select + Start` в разделе «Оформление», чтобы сохранить «Терминал» как активную тему.
- При запуске удерживайте `Select + Start`, чтобы открыть лаунчер в «Терминале» на текущий сеанс.
- При исчезновении или повреждении файла лаунчер покажет «Терминал». После аварийного перезапуска в пределах одной загрузки система также возвращается к встроенной теме.
