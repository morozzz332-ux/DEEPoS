# Самописные модули DEEPoS 0.41

Штатные модули [«Батарея»](../modules/battery), [«Хранилище»](../modules/storage)
и [«Эмуляторы»](../modules/emulators) показывают, как написать модуль с
минимальным использованием ОЗУ. Они работают по запросу и завершаются после ответа.

## Структура модуля

В каталоге с именем модуля создайте `module.toml` и `main.sh`. Используйте
латинские буквы, цифры, дефис и подчёркивание для уникального идентификатора.
Файлы сохраняйте в UTF-8 с переводами строк LF.

```toml
id = "my_module"
name = "Мой модуль"
description = "Краткое описание, которое откроется по Y."
api_version = 3
version = "0.1.0"

[run]
runtime = "sh"
entry = "main.sh"
mode = "ondemand"
```

`main.sh` принимает запросы JSON по одному на строку через stdin и возвращает
ответы с тем же `id` через stdout. Для `initialize` верните
`{"id":1,"result":{"ready":true}}`. По кнопке X приходит
`action.invoke` с `params.action = "inspect"`. Верните, например,
`{"id":2,"result":{"message":"Данные готовы"}}`. Несколько строк в сообщении
разделяйте JSON-последовательностью `\n`. Отладочный вывод пишите в stderr.

Относительные пути отсчитываются от каталога модуля. Для собственных файлов
используйте `MODD_MODULE_DATA`, указывающую на каталог внутри
`/data/module-data`. Режим `daemon` применяют модули с обработчиком
`launch.before`. Выбирайте `ondemand`, если модуль нужен только из меню.

## Установка

1. Скопируйте каталог модуля в `modules` на разделе ROMS карты TF1.
2. На консоли откройте «Модули», нажмите START и затем A. После копирования
   перезагрузите консоль.
3. Выберите модуль. Y показывает описание, A включает его, X вызывает действие.

Импорт добавляет новые каталоги и по умолчанию держит их выключенными. При
установке из Linux или оболочки можно скопировать модуль прямо в
`/data/modules/<id>`, сделать `main.sh` исполняемым и задать `enabled = false`
в манифесте. Модули исполняются с правами службы `modd`, поэтому включайте код,
которому доверяете.
