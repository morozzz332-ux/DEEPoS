# Установка DEEPoS на R36S‑V20

Подготовьте microSD для системы, картридер и компьютер. Для образа 0.41 размер
карты должен быть не меньше 31 103 909 888 байт. Если две карты с маркировкой
«32 ГБ» отличаются по фактическому размеру, используйте более ёмкую.

## 1. Подготовьте карту и образ

1. Выключите консоль и выньте карту из слота **TF1 / OS**. Сохраните её как
   резервную или скопируйте игры и сохранения. Для первой установки удобнее
   взять отдельную карту.
2. Возьмите готовый архив `deepos-r36s-v20-<версия>.img.gz` для R36S‑V20
   из [Releases](https://github.com/morozzz332-ux/DEEPoS/releases) или локальной
   сборки DEEPoS. Ссылка **Source code** ведёт на исходники. Для записи нужен
   файл образа `.img` или `.img.gz`.
3. Сверьте SHA‑256 архива с файлом контрольных сумм этой версии. В PowerShell
   команда выглядит так:

   ```powershell
   Get-FileHash -Algorithm SHA256 .\deepos-r36s-v20-0.41-bundle-r2.img.gz
   ```

Если готового образа для вашей ревизии нет, его можно собрать по
[инструкции разработчика](DEVELOPMENT.md) или запросить у сопровождающего проекта.

## 2. Запишите образ

1. Подключите microSD через картридер. Перенесите нужные файлы с карты:
   запись образа заменит её разметку и содержимое.
2. Откройте [balenaEtcher](https://etcher.balena.io/), выберите **Flash from
   file** и укажите файл образа. Поддерживаемый архив `.img.gz` можно выбрать
   напрямую.
3. Нажмите **Select target**. Сверьте модель и размер съёмного носителя.
   Нажмите **Flash** и дождитесь окончания записи и проверки.
4. После записи Windows может предложить отформатировать служебные разделы.
   Закройте эти окна. Для копирования игр используется раздел **ROMS** с exFAT.
5. Безопасно извлеките карту, вставьте её в выключенную консоль в **TF1 / OS**
   и включите питание. После логотипа откроется меню. При первом запуске
   прошивка добавит штатные модули и папки ROMS.

## 3. Скопируйте игры

1. Подключите карту к ПК через картридер или включите **Настройки → USB‑файлы**
   на консоли и подключите кабель к разъёму **OTG**.
2. Откройте раздел **ROMS**. Если в Windows он виден в «Управлении дисками»,
   но отсутствует в Проводнике, щёлкните правой кнопкой по разделу exFAT с
   меткой ROMS и добавьте свободную букву через **Изменить букву диска или
   путь к диску**.
3. Положите свои файлы в папки систем. Примеры `gba/игра.gba`,
   `snes/игра.sfc` и `psx/игра.chd`. Для систем, которым требуется BIOS,
   используйте `bios/`. Свободный комплект для Atari ST и MSX, а также
   имена файлов для других систем описаны в [руководстве по BIOS](BIOS.md).
4. Безопасно извлеките диск. При копировании через OTG снова нажмите A на
   плитке USB‑файлов, чтобы вернуть раздел лаунчеру. В **Игры** появятся
   системы с найденными файлами. **Select + Start** возвращает из RetroArch
   в DEEPoS.

Для **TF2 / Game** подойдёт отдельная карта с одним разделом exFAT на весь
объём. Существующая карта с разделом `EASYROMS` тоже поддерживается. Скопируйте
в неё такие же папки или используйте `roms/gba`, `roms/psx` и т. д. Вставьте
TF2 до включения. Во вкладке **Файлы** видны статус и количество игр на TF2.
Сейвы RetroArch размещаются на TF1.

## Если что-то не получилось

| Что видно | Что проверить |
| --- | --- |
| Чёрный экран | Карта в TF1, образ для вашей ревизии, запись прошла проверку. Для диагностики сохраните файлы `BOOT/report` и следуйте [плану проверки устройства](DEVICE-TEST-PLAN.md). |
| ROMS виден, игр в меню нет | Названия папок, расширения файлов и наличие эмуляторов для системы. |
| Игра появилась, но не запускается | Проверьте выбранное ядро и нужный [BIOS](BIOS.md). |
| TF2 отсутствует во вкладке «Файлы» | Выключите консоль, переустановите карту и включите заново. Проверьте, что ПК распознаёт раздел. |
